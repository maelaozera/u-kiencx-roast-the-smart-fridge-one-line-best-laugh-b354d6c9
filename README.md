# Roast the Smart Fridge: One Line, Best Laugh Wins

Entry for the make.fun bounty
`u-kiencx-roast-the-smart-fridge-one-line-best-laugh-b354d6c9`.

## The entry

`main.ts` writes a single roast line (at most 160 characters) to
`/output/entry.txt`. The line roasts a smart fridge that takes its
"smart" duties too far: it tracks the writer's midnight snacking,
emails a spreadsheet about it, and cc's the doctor.

## Running it

```sh
node main.ts
```

Deterministic: every run writes the exact same bytes to
`/output/entry.txt`.
